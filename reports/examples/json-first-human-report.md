# Structure of Knowledge: Topology

## Domain Decomposition

Topology is a formal field organized around properties of spaces that persist under continuous maps, with invariants used to compare shape without relying on metric detail.

## Orientation

This compact human report focuses on point-set foundations before algebraic examples. It is a final-stage report input, not an internal scaffold.

| Element | In this field |

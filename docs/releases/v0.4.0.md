# SoK v0.4.0

This release adds graph interchange and clarifies evidence and machine-readable research contracts.

- Export graph snapshots using the new graph input and output schemas.
- Preserve typed relations and strengthen evidence and report validation.
- Split command, relation, import, and HTML rendering logic into smaller modules.
- Update research and collaboration guidance and document the machine contract.

## Release procedure

Run `make test`, `make vet`, `make test-install`, `cargo fmt --manifest-path cli/Cargo.toml --all -- --check`, and `git diff --check` before publishing. Run `make package` to create the portable source-only skill archive. The installer builds the CLI separately.

Push the prepared main branch and confirm GitHub CI succeeds. Create tag `v0.4.0` on that verified commit, then publish a GitHub release using these notes and attach `dist/structure-of-knowledge-skill.tar.gz`. The release has not been published or tagged by this preparation step.
